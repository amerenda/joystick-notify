Controller disconnect while a game is running

Controls what happens if the controller disconnects (battery died, went out of range) while a launched game is still running.

If unchecked, any disconnect returns to desk after the grace period above, regardless of whether a game is still running (the simpler, pre-existing behavior).

Only applies while waiting for a reconnect (above): after the controller has been gone this long, blank the screen and send the TV to CEC standby — without leaving couch mode, so reconnecting resumes instantly instead of redoing the whole switch-over.

Controller shortcut: exit couch mode

Always available while couch mode is active, regardless of what Steam/the game is doing. Only switches display/audio/CEC/screen-lock back to desk — never stops the game.

Hold L1 + R1 + B together for this long to force an exit. A three-button combo is deliberately harder to trigger by accident during normal play than any single button.

Bypass lock screen on connect

Security tradeoff, not a cosmetic setting: this dismisses an active lock screen and disables auto-lock for the duration of couch mode. It makes physical access to this machine equivalent to being logged in while couch mode is active. Only enable this if you're comfortable with that on this specific machine.

Wizard access

Security-relevant, not cosmetic: LAN access means anyone on your network can reach this page (they'll still need the admin password you already set — HTTP Basic Auth, sent unencrypted, so treat that password as only as strong as your LAN's trust level). Takes effect on the next daemon restart.

Unchecked: only reachable from this machine (127.0.0.1). Checked: reachable on all network interfaces (0.0.0.0).

Advanced: specific bind address / port

Overrides the checkbox above if set to something other than 127.0.0.1/0.0.0.0 — e.g. to bind only a specific interface (a VPN/Tailscale IP) rather than every interface.
